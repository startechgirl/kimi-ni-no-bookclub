## 🇧🇷

*Kimi Ni No Bookclub* é uma __aplicação web__ em desenvolvimento para leitores que estão em busca de um espaço simples e com um design aconchegante para as suas leituras!

A ideia nasceu para complementar meus estudos relacionados à __containers__ e __Docker__ para o *deploy* de aplicações no __Amazon Lightsail__. O *Kimi Ni No Bookclub* utiliza __HTML5__, __CSS3__ e __JavaScript__ para o __Front-end__, enquanto os designs foram feitos através do __Figma__. O design inicial conta com uma página para login, uma página para criação de uma nova conta, e quatro páginas dinâmicas dentro da parte principal: uma para __Leituras Atuais__, bem como para pesquisa de novos títulos e atualização de páginas lidas; uma página para __Livros Lidos__, com um ranking composto por até cinco estrelas como nota; uma página de __Bookmarks__ para o arquivamento das suas citações e frases favoritas; e, por último, mas não menos importante, uma página de __Minha Conta__, que permite a edição do e-mail, nome de usuário, senha e avatar, bem como o *logout* da conta.

O *Kimi Ni No Bookclub* une meus principais interesses no campo da tecnologia - __design__, __Front-end__ e __Cloud Computing__ - com o meu amor incondicional pelos __livros__. Espero que você possa aproveitar e usar esse projeto da melhor maneira possível tanto quanto eu amei desenvolvê-lo! <3

## 🇺🇸

*Kimi Ni No Bookclub* is a __web application__ currently under development, designed for readers that are looking for a simple and cozy space for their reading journey!

The idea was born out of my studies on __containers__ and __Docker__ for deploying applications on __Amazon Lightsail__. *Kimi Ni No Bookclub* uses __HTML5__, __CSS3__, and __JavaScript__ for the __Front-end__, with designs created on __Figma__. The initial design features a login page, a sign-up page, and four dynamic pages within the main section: one for __Current Reads__, where users can search for new titles and update their reading progress; a __Read Books__ page, featuring a five-star rating system; a __Bookmarks__ page, to save ur favorite quotes; and, last but not least, a __My Account__ page, which allows users to edit their email, username, password, and avatar, as well as log out.

*Kimi Ni No Bookclub* combines my key tech interests —__design__, __Front-end development__ and __cloud computing__— with my unconditional love for __books__. I hope you enjoy using this project as much as I love coding it! <3
